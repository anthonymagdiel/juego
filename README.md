# NEON DRIFT

Arcade web de supervivencia hecho con HTML, CSS y JavaScript, sin dependencias ni servidor.

## Ejecutar

Abre `index.html` directamente en un navegador moderno. El récord y las preferencias se guardan en el almacenamiento local del navegador.

## Controles

- Teclado: `←` / `→` o `A` / `D` para moverte.
- Móvil: botones de dirección o arrastra el dedo por el campo de juego.
- `P` o `Esc` para pausar o continuar.

Esquiva los asteroides, recoge los cristales de energía y sobrevive para avanzar de nivel. La música, los efectos y la dificultad inicial se ajustan desde Configuración.
